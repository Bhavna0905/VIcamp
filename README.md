
# VIcamp – Voice AI Campaign Analytics

An interactive analytics dashboard for monitoring Voice AI calling campaigns, analyzing call outcomes, tracking campaign performance, and identifying potential data-quality issues.

## Project Overview

VIcamp analyzes lead and call records generated by Voice AI campaigns. It combines Python, Pandas, SQL, and SQLite to process campaign data and presents actionable insights through an interactive Streamlit dashboard.

The project currently uses synthetic sample data to demonstrate the analytics pipeline.

## Key Features

### 1. Campaign Performance Analytics
- Total leads and calls
- Connected calls and conversions
- Connection rate and conversion rate
- Campaign-wise performance comparison

### 2. Data Quality Monitoring
- Missing value detection
- Duplicate ID detection
- Calls without matching leads
- Negative call duration checks
- Missing transcripts in connected calls

### 3. Call Outcome Validation
- Compares recorded call outcomes with transcript keywords
- Identifies potential outcome mismatches
- Classifies records as OK, MISMATCH, or REVIEW
- Generates a CSV validation report

### 4. Interactive Dashboard
- Campaign-level filters
- KPI cards
- Campaign comparison charts
- Call outcome distribution
- Call duration analysis
- Detailed call records

## Data Pipeline

1. Generate or collect lead and call records in CSV format.
2. Use Pandas to read and inspect the datasets.
3. Run data-quality checks to identify potential issues.
4. Load lead and call records into SQLite tables.
5. Use SQL queries to analyze campaign performance.
6. Validate recorded call outcomes against transcript keywords.
7. Visualize the results through the Streamlit dashboard.

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/Bhavna0905/VIcamp.git
cd VIcamp
```

### 2. Install dependencies

```bash
python -m pip install -r requirements.txt
```

### 3. Generate sample data

```bash
python scripts/generate_data.py
```

### 4. Run data-quality checks

```bash
python scripts/data_quality.py
```

### 5. Create and load the SQLite database

```bash
python scripts/load_database.py
```

### 6. Run campaign analysis

```bash
python scripts/campaign_analysis.py
```

### 7. Validate call outcomes

```bash
python scripts/outcome_validation.py
```

### 8. Launch the dashboard

```bash
streamlit run app.py
```

Open the local URL displayed in your terminal, usually:

```text
http://localhost:8501
```

## Key Metrics

**Connection Rate**

Connected Calls / Total Calls × 100

**Conversion Rate**

Converted Leads / Total Leads × 100

## Current Limitations

- Uses synthetic sample datasets rather than live voice-calling provider data.
- Outcome validation is rule-based keyword matching, not LLM-based semantic analysis.
- Data processing and report generation are currently triggered manually.
- Dashboard metrics depend on the available sample records.
